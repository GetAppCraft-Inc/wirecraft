# xwire build — progress

Stack (user-chosen 2026-11-11): **Tauri 2 + Svelte 5/TS UI** over a **Rust MITM core**. Scope for v1: real proxy +
3-pane workspace + onboarding, matching `design/` (source of truth; tokens in `design/generator/lib.py`).

## Done
- Cargo workspace (`Cargo.toml`: members `crates/xwire-core`, `src-tauri`).
- `crates/xwire-core` — builds, unit tests pass, smoke-tested with curl:
  - `ca.rs` CA gen/load (ECDSA P-256, `~/.local/share/xwire/ca/xwire-root.{pem,crt,der,key}`), per-host leaf certs cached, SNI resolver.
  - `proxy.rs` HTTP/1.1 proxy, CONNECT → TLS intercept (h2+h1 to client, auto builder) or blind tunnel; upstream
    hyper-util client (h1+h2, native roots) + h1-only client for WebSocket upgrades; Host header stripped (h2 safe);
    TLS-rejection/pinning recorded as CONNECT error flow; `xwire.check` / `xwire.cert` special hosts; landing page
    on direct hits; `replay(id)`; intercept modes All/Listed/Off + never-decrypt globs.
  - `store.rs` flows + broadcast events (Upsert/Removed/Cleared), recording toggle, cap.
  - `body.rs` TeeBody (captures response while streaming; finishes on is_end_stream), gzip/deflate/br/zstd decode, type classify.
  - `procinfo.rs` Linux /proc client-process lookup (Client column) + User-Agent fallback.
  - `examples/headless.rs` — `cargo run --example headless -- 127.0.0.1:9090` (env `XWIRE_CA_DIR`).
- `src-tauri/`: Cargo.toml, build.rs, tauri.conf.json (decorations off, 1440×900, min 1024×700, devUrl :1420),
  capabilities/default.json, icons (generated from icons/xwire.svg), `src/settings.rs`, `src/system.rs`
  (os info, trust status/install for p11-kit/NSS/Firefox/macOS/Windows, GNOME/KDE system proxy, port check, LAN ip).
- npm: package.json with vite 8, svelte 5, @sveltejs/vite-plugin-svelte 7, typescript 6, @tauri-apps/cli+api 2,
  plugin-dialog, plugin-clipboard-manager, @fontsource-variable/inter, @fontsource/jetbrains-mono.

- `src-tauri/src/lib.rs` (AppState, proxy restart with port-release retry, store events batched every 60 ms as `flows`,
  `resync` on lag, `stats` 1/s, `proxy` on restart; system proxy restored on quit) + `har.rs` (HAR 1.2 export) + `main.rs`.
  Commands: app_state, stats, list_flows, flow_detail (bodies decoded, clipped at 4 MB), search_bodies, save_body,
  set_recording, clear/remove_flows, replay, export_har, restart_proxy, set_intercept, set_prefs, check_port, lan_ip,
  ca_info/ca_pem/export_ca, trust_status, install_ca_system, install_nss, manual_commands, regenerate_ca,
  verify_interception (curl https://xwire.check via proxy), qr_svg, system_proxy/set_system_proxy.
- Core fix: TeeBody no longer reports empty bodies (204/304/Content-Length: 0) as "client closed" errors.
- Frontend (Svelte 5, `src/`): tokens.css + icons.ts generated by `scripts/gen-design-tokens.py` from
  `design/generator/lib.py`. Workspace: toolbar (record/pause/clear, proxy+CA status, palette), sidebar (App/Domain/
  Device trees, pinned, favourites via right-click, HAR export), filter bar (query language in `lib/query.ts` with
  highlighting, autocomplete, saved/recent filters, chips with counts), virtualized table (sort, column picker,
  follow-tail + new-requests pill, multi-select, context menu with Copy as cURL/fetch/Python/Go/reqwest/HTTPie),
  inspector (request/response tabs, Pretty/Raw/Tree/Hex/Preview, Auth with JWT decode, Timing, TLS), status bar,
  toasts, command palette, shortcuts. <1200 px → icon rail + bottom inspector. Onboarding: Welcome, Root CA
  (6 platforms, pkexec/NSS install, manual commands, verify, QR for phones, regenerate), Proxy & port.
- Verified in `npx tauri dev` (GDK_BACKEND=x11) with curl traffic: capture, table, inspector, JSON body render.

- Rules engine (`crates/xwire-core/src/rules.rs`, wired into `proxy.rs` `exchange()` → `respond()`):
  Map Local (inline body or file), Map Remote (prefix or replace path), Rewrite (req/resp headers, query param, URL,
  req/resp body, status; set/add/remove/find-replace incl. regex), Breakpoints (request and/or response, edit
  method/URL/status/headers/body, abort), Block (403), Throttle (latency, up/down kbit/s, per-host). Response rules
  buffer ≤32 MB and strip Content-Encoding. Flows carry `applied` labels and `FlowState::Paused`.
- WebSocket capture (`ws.rs` frame parser, `Sec-WebSocket-Extensions` stripped so payloads stay readable);
  messages stored per flow (cap 5000 × 64 KB), shown in the inspector's Messages tab.
- `Proxy::send` (Compose / Edit and repeat; replay uses it, returns the new id immediately).
- App: rules persisted in settings.json; commands get/set_rules, paused, resume, resume_all, send_request,
  ws_messages, import_har, list/save/delete_session (HAR files in `<data>/xwire/sessions`).
- UI: toolbar tools live with counts; RulesSheet (all six tools), PausedEditor in the inspector, Compose, Diff
  (headers + LCS body diff), WsMessages, saved sessions + HAR import in the sidebar, rule items in the row menu,
  status-bar rule summary, palette commands, shortcuts E / B / D.
- Tests: `cargo test --workspace` — unit (rules, ws parser, HAR round trip) + e2e (`tests/rules.rs`,
  `tests/websocket.rs`) through the real proxy.
